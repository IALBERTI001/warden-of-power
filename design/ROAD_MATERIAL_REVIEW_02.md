# Road material revision

The user rejected the pale clean walkway as visually mismatched with the weathered courtyard, and explicitly said the towers look good. Tower artwork and placement are therefore untouched by this revision.

New candidate: `game/assets/broken-conduit-weathered-road-v2.png`. The built-in image tool edited the integrated scene using it as the reference. Prompt restricted changes to road material and edge weathering: same warm-gray stone grain, chipped edges, irregular cracks, dirt-filled seams, restrained moss, local lighting and a subtler worn-center value difference, while preserving route geometry, doorways and architecture. The resulting candidate is saved separately; earlier scene images are retained.

The live map reference now uses this candidate, including doorway foreground re-sampling from the same image. No procedural road is drawn over it. Enemy path coordinates, portal masks, tower images, gameplay rules and save version are unchanged. The subdued path must still be judged for gameplay readability in user review; material matching alone does not establish successful wayfinding. Do not describe this art as approved or visually verified in the browser.
