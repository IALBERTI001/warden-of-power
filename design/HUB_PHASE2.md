# Phase 2 — The home hub (first playable, Oct 22 2026)

Open `game/hub.html` (local: http://127.0.0.1:8124/game/hub.html). The tutorial's results screen and the in-game ⌂ button return here.

- Painted hub from the approved concept. Pins for the Outer Seal, five facilities and the sealed Aetherheart Engine show state in words (Ruined / Restoring 1/3 / Reawakened) plus pips; "!" marks an affordable restoration.
- Facility panel slides over the map: three restoration stages with exact Parts cost and bonus, then its skill branch. Reawakening fades in the restored painting for that area and awards its badge.
- Skill tree: the approved 20 nodes in five branches; select never spends, separate Buy; free reassignment (click twice); Mastery tiers appear once a branch is complete (open at endless milestones).
- Badges gallery, Next-step button that always names the most useful action.
- Rewards: tutorial first clear 80 Parts, replays 20; Seals Cleared / Held (seal ≥ 75%) / Challenge (all three combos) pay 40 Resonance each, first time only.
- Saves: automatic in the browser; Settings → Copy save code / Load this save code moves progress between browsers or PCs. Test tools (+100 Parts, +100 Resonance, pretend wave 100, reset all) are behind a checkbox.
- Accessibility: every pin and node is a button with a spoken name; Esc closes panels; states are words, not colour only; 44 px targets; reduced motion respected.

Gate (per plan): your approval of the hub + keyboard-only run-through (verified headless: Tab to a pin, Enter opens, Esc closes).
Not yet: campaign missions (Phase 3), per-stage hub painting (only the fully reawakened state is painted), Atelier art for intermediate stages.

## First-visit guide (Oct 22 2026, per user direction)
- A brand-new player opening the hub is sent straight to the tutorial; the in-game ⌂ hub button and "Return to the hub" stay hidden until the first tutorial win.
- First win: the results button reads "Enter the Containment Complex".
- Welcome card explains Restoration Parts (rebuild the complex) and Resonance (learn skills), with the amounts just earned. "Show me" or "Skip the guide".
- Six guided steps, each pointing at the real control and advancing only on the real action: open Moonwell Cisterns → restore stage 1 (opens Water skills) → open Water skills → buy a first skill → Warden Power explained → the Next Step button. A first win always affords both (80 Parts vs 40; ≥40 Resonance vs 25).
- Each resource in the top bar is a button that explains itself. The ? button replays the guide. Guide progress is stored in the profile, so it travels with save codes.
