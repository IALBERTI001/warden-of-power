1. GOAL, SETTING, AND PLAYER EXPERIENCE
--------------------------------------

Goal: create an excellent, polished browser tower-defense game, developed locally,
ultimately meeting CrazyGames requirements for full publication. Re-check the
current official CrazyGames developer requirements when doing platform work;
this project has not completed that audit or submission process.

Working title: Warden of Power.
Player role: Warden of Power, defending an ancient elemental containment complex.
Enemies are manifestations of unstable power. Magical towers protect containment
seals and recapture power. The former garden Keeper framing was superseded.

First map/tutorial: The Broken Conduit, Outer Seal / Sector I.
The map should tell this world's story, not be a random decorative backdrop.

Desired loop:
- Enter play with clear objectives and readable threats.
- Spend run currency (Charge) on elemental towers and upgrades.
- Start waves, earn Charge from enemies and wave clears.
- Build, upgrade, retarget, sell, and adapt in real time, including during waves.
- Combine elements, earn achievements, and learn from visible feedback.
- Finish runs and progress toward restoration/campaign goals.
- Eventually unlock endless mode, earn permanent endless progression, and pursue
  personal records and the player ladder.

Player flexibility is essential. Pause and 1x / 2x / 5x speed remain available.
Clear resource costs/refunds and responsive hotkeys are required. Avoid needless
screens or interface clutter that obscure the game.


2. CURRENT IMPLEMENTATION: WHAT REALLY EXISTS
--------------------------------------------

Plain HTML/CSS/JavaScript game with Canvas 2D rendering and browser Audio playback.
No frontend framework, npm package dependency, bundler, database, or server API.
Scripts use browser globals/CommonJS-compatible modules rather than a build chain.

Implemented in the playable local tutorial:
- Exactly FIVE combat waves, ending after the fifth clears.
- Shared wave total/formatter used by HUD, next-wave preview, and results.
- Fire, Water, Ice, Lightning towers.
- Free placement on clear valid ground, not restricted to predefined pads.
- Placement blocks the road, door approaches, boundaries, and overlapping towers.
- Tier I, Tier II, and Tier III with two specialization choices at Tier III.
- Tier-dependent tower artwork; upgraded artwork remains a review candidate
  unless separately approved. Preserve identities rather than redesigning them.
- Upgrades during combat, without resetting cooldowns for a free shot.
- Sell with confirmation. Unused towers refund 100% of actual spending; towers
  that have fired refund 75%, rounded down.
- First / Last / Strongest / Nearest targeting.
- Persistent targeting policy badges ABOVE EVERY tower, including when idle:
  arrow/1 First, reversed arrow/1 Last, flexed arm Strongest, bullseye Nearest.
  These indicate policy, not a claim that a particular enemy is currently hit.
- Animated enemy movement, death sequences, status visuals and combo effects.
- Pause, speed controls, remappable keyboard controls, audio settings.
- A closable, paged tutorial handbook with 14 reference pages.
- Local achievement catalog, counters, banked Restoration Parts, resumable run,
  settings and hotkeys in browser localStorage.
- Approved original Warden Quill font, bundled locally.
- Approved v3 elemental tower sounds.

NOT implemented as production systems:
Campaign maps/restoration facilities; playable endless mode; actual skill-tree
purchases applied to endless combat; cloud/account saves; online top-10 ladder;
validated competitive submissions; CrazyGames SDK integration; finished badge
art; final approved soundtrack/ambience; complete production animation sets;
full device/browser/accessibility/performance QA; release packaging/submission.

The engine has a boss type with shorter freeze, but the current five-wave
course ends with mixed enemies, not the old eight-wave boss finale.


3. EXACT CURRENT TUTORIAL AND MECHANICS
--------------------------------------

Current waves in game/engine.js:
1. Fire & burning: 6 slimes.
2. Water + ice: hold the line: 5 golems.
3. Lightning: connected crowds: 14 swarm enemies.
4. Fire + ice: shatter: 6 golems.
5. Your elemental defense: 16 mixed enemies.

Fire is initially available. Water AND Ice unlock after wave 1 clears.
Lightning unlocks after wave 2 clears.
Start with 165 Charge and 20 seal integrity.
Wave 1 clear grants 140 preparation Charge; wave 2 grants 90; later clears grant
45, plus enemy kill earnings. Teaching golems on waves 2/4 have 1.35x health to
allow combinations to occur. These values are tutorial tuning, not final campaign
balance promises.

Every display of combat progress must agree with the actual total. On victory,
show 5 / 5, never 5 / 8. Use engine WAVES and waveProgress(), not independent
hardcoded denominators. Handbook page counts are independent REFERENCE pages,
not combat waves. Achievement counts derive from ACHIEVEMENTS.length.

Handbook behavior:
- Persistent Warden's Handbook button opens/closes it at any time.
- Previous/Next freely navigate all 14 pages without completing actions first.
- Remember reading position, including after closing.
- Battle continues while the nonmodal book is open; closing frees the view.
- Escape closes the book. Restart returns to page one.
- Show me closes the book and highlights the relevant battlefield control/panel.
- Show me MUST NOT buy, upgrade, sell, or open a transaction confirmation.
- The sell lesson is informational with an Understood button; selling is optional.
- Reading position and actual performed actions/combos are separate state.
- Opening a new wave is not gated on reading the handbook.

Current tier-I tower values (engine is authoritative for numerical changes):
Fire:      60 Charge; 14 damage; 0.85s interval; 160 range.
Water:     65 Charge;  5 damage; 0.92s interval; 165 range.
Ice:       75 Charge;  8 damage; 1.10s interval; 155 range.
Lightning: 90 Charge; 16 damage; 1.22s interval; 165 range.

Tier II: 1.55x base damage, +12 range, interval x0.82.
Tier III: 2.15x base damage, +24 range, interval x0.72, plus specialization.
First upgrade cost: 65 + round(base tower cost x0.3).
Tier III cost: 130 + round(base tower cost x0.5).

Specializations:
Fire: Wildfire / Fracture furnace.
Water: Deluge / Pressure Lance.
Ice: Cold front / Crystal focus.
Lightning: Chain reaction / Focused current.
Read stats() for exact effects; do not infer upgrades from art alone.

Element/status contract:
- Fire deals direct damage and burning for 3 seconds.
- Water deals light damage and applies Soaked (4 seconds at Tier I; longer when
  upgraded). SOAKED BY ITSELF DOES NOT SLOW. It is a combo primer.
- Ice applies Chilled for 2.7 seconds, slowing 24% at Tier I.
- Ice hitting a Soaked, eligible enemy consumes Soaked and freezes it for 1.5s.
- Extra hits cannot refresh/extend an existing freeze or bypass freeze resistance.
- Natural thaw grants 4 seconds freeze resistance.
- Fire hitting frozen enemies shatters them, dealing area burst damage and ending
  the freeze. Resistance after shatter is 2 seconds, HALF natural thaw recovery.
  The user's quarter-time idea was discussed; the accepted current rule is 2s.
- Boss freeze duration is currently 0.75s in the engine.
- Lightning hitting a Soaked target can conduct to nearby enemies (up to 3 total
  chain targets at Tier I; certain upgrades increase this).
- Badges require real resolved combo events, not merely building towers together.
- First real status/combo occurrences give explanatory notices; tower inspector
  and field manual also explain the mechanics.

Default keys:
1 Fire; 2 Water; 3 Ice; 4 Lightning.
U focuses/reviews upgrades; X opens sell confirmation; T cycles target policy.
Space pause; N next/early wave; Z 1x; C 2x; V 5x.
Escape/right click cancel placement/selection (Escape first closes the book).
Settings support remapping. Do not break text-field/select keyboard interaction.

OPTIONAL MANUAL SAVE TRANSFER (your own local data only):
On the old PC, in the browser where your game/save exists, open developer tools
and run this in its Console. It downloads a JSON backup:

  (() => {
    const keys = ['warden.profile.v1','warden.settings.v1',
                  'warden.keys.v1','warden.run.v1'];
    const data = Object.fromEntries(keys.map(k => [k, localStorage.getItem(k)]));
    const url = URL.createObjectURL(new Blob([JSON.stringify(data, null, 2)],
                                            {type:'application/json'}));
    const a = document.createElement('a');
    a.href = url; a.download = 'warden-save-transfer.json'; a.click();
    setTimeout(() => URL.revokeObjectURL(url), 1000);
  })();

Copy that JSON separately to the new PC. Open the game at your chosen consistent
origin, then run this Console snippet to choose and import the backup:

  (() => {
    const keys = ['warden.profile.v1','warden.settings.v1',
                  'warden.keys.v1','warden.run.v1'];
    const input = document.createElement('input'); input.type = 'file';
    input.accept = '.json,application/json';
    input.onchange = async () => {
      const data = JSON.parse(await input.files[0].text());
      for (const k of keys) {
        if (!Object.hasOwn(data, k) ||
            (data[k] !== null && typeof data[k] !== 'string')) {
          throw new Error('Not a compatible Warden save backup');
        }
        if (data[k] !== null) JSON.parse(data[k]);
      }
      for (const k of keys) {
        if (data[k] === null) localStorage.removeItem(k);
        else localStorage.setItem(k, data[k]);
      }
      location.reload();
    };
    input.click();
  })();

Back up any save already on the new PC first: import replaces these four keys.
These optional snippets are instructions, not a built-in game feature or an
end-to-end browser-tested transfer. Current run restore expects version 1,
tutorialVersion 3 and a valid <=5-wave run. Old incompatible practice runs reset
while separately banked profile badges/Parts remain.
